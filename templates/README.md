# Project templates

Templates are optional starting points for artifacts in a target repository. Factory copies one only when the target lacks an equivalent and the task authorizes the new file.

- `project/product-brief.md` captures the problem and boundaries.
- `project/specification.md` defines behavior and acceptance criteria.
- `project/architecture-decision.md` records a consequential technical choice.

Do not overwrite project-native templates or instructions. Adapt wording to the target rather than forcing a Factory format onto it.

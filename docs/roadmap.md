# Roadmap

## Factory v0

Codex, installed skills, local Git, deterministic project commands, and manual browser testing. Humans select tasks, targets, and tools.

## Factory v1

Add a safe project inspector and runner, external search through one adapter, Playwright browser verification, cost-aware model routing, and the smallest useful set of roles. Runs produce structured local artifacts and stop at approval gates.

## Factory v2

Add stronger orchestration, resumable runs, selected MCP or API integrations, GitHub pull-request automation, and controlled deployment adapters. Introduce integrations only after their permissions and costs are observable.

## Factory v3

Support idea to research, specification, build, test, review, and deployment with minimal human intervention. Humans retain policy, budget, credential, high-risk architecture, and production deployment control.

## Near-term order

1. Use the bounded researcher workflow to prepare the first product brief and specification.
2. Add a small check planner for detected project scripts and browser plans.
3. Add controlled lifecycle management for an already-approved development server command.
4. Measure real tasks before implementing model routing or multi-agent scheduling.
